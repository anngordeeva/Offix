# Инструкция по развертыванию SPA на Vercel

## Проблема
При прямом переходе на URL типа `https://offix.vercel.app/contacts` сервер возвращал 404 ошибку, потому что физически такой страницы не существует.

## Решение
1. **Создан файл `vercel.json`** - настраивает Vercel для работы с SPA
2. **Исправлен роутинг в `App.js`** - улучшена логика обработки прямых переходов по URL

## Что было сделано

### 1. Файл `vercel.json`
```json
{
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ]
}
```
Этот файл говорит Vercel перенаправлять все запросы на `index.html`, что позволяет JavaScript роутеру обрабатывать маршруты.

### 2. Исправления в `App.js`
- Улучшена логика инициализации приложения
- Исправлена обработка прямых переходов по URL
- Убраны console.log для production
- Исправлены ошибки линтера

## Как протестировать

1. **Соберите проект:**
   ```bash
   npm run build
   ```

2. **Разверните на Vercel:**
   ```bash
   vercel --prod
   ```

3. **Проверьте работу:**
   - Перейдите на главную страницу: `https://offix.vercel.app/`
   - Попробуйте прямой переход: `https://offix.vercel.app/contacts`
   - Проверьте другие страницы: `/about-us`, `/offices`, `/virtual-office`
   - Убедитесь, что кнопка "Назад" работает корректно

## Ожидаемое поведение
- Все прямые переходы по URL должны работать корректно
- SPA роутинг должен функционировать без перезагрузки страницы
- Кнопка "Назад" браузера должна работать правильно
- 404 страница должна показываться для несуществующих маршрутов
